# Student Skill & Career Analytics System

Student Skill & Career Analytics System is a Python-based desktop application developed using CustomTkinter. It analyzes student academic performance, technical skills, and career readiness.

## Features

- Student data management
- Academic performance analysis
- Technical and personal skill analysis
- Interview-readiness score calculation
- Career recommendations
- Skill-gap identification
- Learning recommendations
- Interview preparation guidance
- Student record management
- Academic performance visualization

## Technologies Used

- Python
- CustomTkinter
- Pandas
- NumPy
- Matplotlib
- CSV

## Project Structure

- `app.py` – Main Python application
- `student_data.csv` – Student dataset
- `requirements.txt` – Required Python libraries
